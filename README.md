\# Projects



\## Task 1 — Basic Network Sniffer



\*\*Folder:\*\* `CodeAlpha\_Task1\_Basic\_Network\_Sniffer`



A Python-based network packet analyzer built using \*\*Scapy\*\*.



\### Features



\- Captures live network packets

\- Identifies IPv4 traffic

\- Detects TCP, UDP and ICMP protocols

\- Displays source and destination IP addresses

\- Displays source and destination ports

\- Displays packet size and TTL

\- Extracts a limited packet payload

\- Saves packet information to CSV

\- Saves captured packets as PCAP

\- Provides protocol statistics



\### Technologies



\- Python

\- Scapy

\- CSV

\- PCAP
