# CodeAlpha Cyber Security Internship

# Task 1 – Basic Network Sniffer

## Objective

Develop a Python application capable of capturing live network packets and displaying useful information such as source IP, destination IP, protocols, ports, packet size, and payload preview.

---

## Technologies Used

- Python
- Scapy
- Colorama

---

## Working

The application continuously monitors network traffic using the Scapy library.

For every captured packet, the following information is extracted:

- Timestamp
- Source IP Address
- Destination IP Address
- Protocol
- Source Port
- Destination Port
- Packet Size
- Payload Preview

The packet information is also stored in a CSV file for later analysis.

---

## Features

- Live Packet Capture
- Protocol Detection
- CSV Logging
- Payload Inspection
- Easy-to-use Command Line Interface

---

## Output

The program successfully captures network packets generated while browsing the internet and displays detailed packet information in real time.
